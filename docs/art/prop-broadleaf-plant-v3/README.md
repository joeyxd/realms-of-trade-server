# prop-broadleaf-plant-v3

broadleaf-plant (manifest id `prop:broadleaf-plant`, replaces the procedural `broadleaf`).

- Origin: Tripo web studio, 2026-10-19, image-to-3D from the concept image. Original: `broadleaf-plant-v3-original.glb` (4405 tris, 1.2 MB). Concept: `broadleaf-plant-v3-concept.png`.
- LOD source: `broadleaf-plant-v3-lod.glb` = gltf-transform simplify --ratio 0.6039 --error 0.02 (2753 tris). Bounds x -0.443..0.443, y -0.414..0.408, z -0.498..0.500.
- Game derivatives (assets/models): `prop-broadleaf-plant-v3-desktop.glb` (2753 tris, 512 WebP, 238288 B) and `prop-broadleaf-plant-v3-mobile.glb` (256 WebP, 194888 B).
- Budget: 2800 (2800 tris), texture 512 PC / 256 mobile.
- Runtime: toon material and ink outline come from the game renderer (registry/toonmat), not from the GLB.
