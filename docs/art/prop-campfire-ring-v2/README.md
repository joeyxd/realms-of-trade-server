# prop-campfire-ring-v2

campfire-ring (manifest id `prop:campfire-ring`, replaces the procedural `campfire`).

- Origin: Tripo web studio, 2026-10-20, image-to-3D from the concept image. Original: `campfire-ring-v2-original.glb` (2000 tris, 2.2 MB). Concept: `campfire-ring-v2-concept.png`.
- LOD source: `campfire-ring-v2-lod.glb` = plain copy of the original (within budget) (2000 tris). Bounds x -0.486..0.486, y 0.000..0.225, z -0.482..0.482.
- Game derivatives (assets/models): `prop-campfire-ring-v2-desktop.glb` (2000 tris, 512 WebP, 206960 B) and `prop-campfire-ring-v2-mobile.glb` (256 WebP, 113416 B).
- Budget: 2000 (2000 tris), texture 512 PC / 256 mobile.
- Runtime: toon material and ink outline come from the game renderer (registry/toonmat), not from the GLB.
