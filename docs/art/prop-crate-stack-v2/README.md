# prop-crate-stack-v2

crate-stack (manifest id `prop:crate-stack`, replaces the procedural `crate`).

- Origin: Tripo web studio, 2026-10-20, image-to-3D from the concept image. Original: `crate-stack-v2-original.glb` (2502 tris, 2.9 MB). Concept: `crate-stack-v2-concept.png`.
- LOD source: `crate-stack-v2-lod.glb` = plain copy of the original (within budget) (2502 tris). Bounds x -0.383..0.383, y 0.000..0.973, z -0.340..0.340.
- Game derivatives (assets/models): `prop-crate-stack-v2-desktop.glb` (2502 tris, 512 WebP, 288492 B) and `prop-crate-stack-v2-mobile.glb` (256 WebP, 167760 B).
- Budget: 2502 (2502 tris), texture 512 PC / 256 mobile.
- Runtime: toon material and ink outline come from the game renderer (registry/toonmat), not from the GLB.
