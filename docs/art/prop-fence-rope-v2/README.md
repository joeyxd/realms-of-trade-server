# prop-fence-rope-v2

fence-rope (manifest id `prop:fence-rope`, replaces the procedural `fence`).

- Origin: Tripo web studio, 2026-10-20, image-to-3D from the concept image. Original: `fence-rope-v2-original.glb` (1500 tris, 2.8 MB). Concept: `fence-rope-v2-concept.png`.
- LOD source: `fence-rope-v2-lod.glb` = plain copy of the original (within budget) (1500 tris). Bounds x -0.489..0.489, y 0.000..0.681, z -0.105..0.105.
- Game derivatives (assets/models): `prop-fence-rope-v2-desktop.glb` (1500 tris, 512 WebP, 237284 B) and `prop-fence-rope-v2-mobile.glb` (256 WebP, 116260 B).
- Budget: 1500 (1500 tris), texture 512 PC / 256 mobile.
- Runtime: toon material and ink outline come from the game renderer (registry/toonmat), not from the GLB.
