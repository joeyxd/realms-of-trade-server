- Game derivatives (assets/models): `prop-fern-cluster-v3-desktop.glb` (4515 tris, 512 WebP, 371780 B) and `prop-fern-cluster-v3-mobile.glb` (256 WebP, 329636 B).
- Budget: 4600 (4600 tris), texture 512 PC / 256 mobile.
- Runtime: toon material and ink outline come from the game renderer (registry/toonmat), not from the GLB.
