# prop-lantern-post-v2

lantern-post (manifest id `prop:lantern-post`, replaces the procedural `lantern`).

- Origin: Tripo web studio, 2026-10-20, image-to-3D from the concept image. Original: `lantern-post-v2-original.glb` (2500 tris, 2.4 MB). Concept: `lantern-post-v2-concept.png`.
- LOD source: `lantern-post-v2-lod.glb` = plain copy of the original (within budget) (2500 tris). Bounds x -0.233..0.233, y 0.000..0.978, z -0.155..0.155.
- Game derivatives (assets/models): `prop-lantern-post-v2-desktop.glb` (2500 tris, 512 WebP, 239236 B) and `prop-lantern-post-v2-mobile.glb` (256 WebP, 133628 B).
- Budget: 2500 (2500 tris), texture 512 PC / 256 mobile.
- Runtime: toon material and ink outline come from the game renderer (registry/toonmat), not from the GLB.
