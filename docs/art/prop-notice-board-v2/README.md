# prop-notice-board-v2

notice-board (manifest id `prop:notice-board`, replaces the procedural `board`).

- Origin: Tripo web studio, 2026-10-20, image-to-3D from the concept image. Original: `notice-board-v2-original.glb` (2004 tris, 2.7 MB). Concept: `notice-board-v2-concept.png`.
- LOD source: `notice-board-v2-lod.glb` = plain copy of the original (within budget) (2004 tris). Bounds x -0.489..0.489, y 0.000..0.886, z -0.213..0.213.
- Game derivatives (assets/models): `prop-notice-board-v2-desktop.glb` (2004 tris, 512 WebP, 256156 B) and `prop-notice-board-v2-mobile.glb` (256 WebP, 142772 B).
- Budget: 2004 (2004 tris), texture 512 PC / 256 mobile.
- Runtime: toon material and ink outline come from the game renderer (registry/toonmat), not from the GLB.
