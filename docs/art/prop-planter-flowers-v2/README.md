# prop-planter-flowers-v2

planter-flowers (manifest id `prop:planter-flowers`, replaces the procedural `planter`).

- Origin: Tripo web studio, 2026-10-20, image-to-3D from the concept image. Original: `planter-flowers-v2-original.glb` (3000 tris, 2.9 MB). Concept: `planter-flowers-v2-concept.png`.
- LOD source: `planter-flowers-v2-lod.glb` = plain copy of the original (within budget) (3000 tris). Bounds x -0.491..0.491, y 0.000..0.913, z -0.429..0.429.
- Game derivatives (assets/models): `prop-planter-flowers-v2-desktop.glb` (3000 tris, 512 WebP, 306656 B) and `prop-planter-flowers-v2-mobile.glb` (256 WebP, 183992 B).
- Budget: 3000 (3000 tris), texture 512 PC / 256 mobile.
- Runtime: toon material and ink outline come from the game renderer (registry/toonmat), not from the GLB.
