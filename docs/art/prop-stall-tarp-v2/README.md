# prop-stall-tarp-v2

stall-tarp (manifest id `prop:stall-tarp`, replaces the procedural `stallTarp`).

- Origin: Tripo web studio, 2026-10-20, image-to-3D from the concept image. Original: `stall-tarp-v2-original.glb` (4015 tris, 3.2 MB). Concept: `stall-tarp-v2-concept.png`.
- LOD source: `stall-tarp-v2-lod.glb` = plain copy of the original (within budget) (4015 tris). Bounds x -0.492..0.492, y 0.000..0.945, z -0.383..0.383.
- Game derivatives (assets/models): `prop-stall-tarp-v2-desktop.glb` (4015 tris, 512 WebP, 365528 B) and `prop-stall-tarp-v2-mobile.glb` (256 WebP, 234712 B).
- Budget: 4015 (4015 tris), texture 512 PC / 256 mobile.
- Runtime: toon material and ink outline come from the game renderer (registry/toonmat), not from the GLB.
