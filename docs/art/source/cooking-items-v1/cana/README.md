# Entrega: Caña de azúcar

Pon aquí el GLB exportado de Tripo: **`cana-v1.glb`**.
Si ya tiene otro nombre, déjalo tal cual; no hace falta repetir la exportación.

[Referencia PNG](../../../cooking-icons-v1/singles/cana.png)

Referencia lista. Mesh pendiente de recepción; priorizar según su uso visible en el juego.

Conserva el original. Para otra versión usa `cana-v2.glb`; si hay texturas externas o un ZIP de Tripo, déjalos junto al modelo. El GLB preferido lleva sus texturas incluidas.

Objetivo inicial 500–800 triángulos; la jarra de grog puede llegar a aproximadamente 1.000.
Texturas derivadas 512/256 px se preparan durante la integración. No necesitas modificar `assets/manifest.json` ni copiar el original al runtime.
