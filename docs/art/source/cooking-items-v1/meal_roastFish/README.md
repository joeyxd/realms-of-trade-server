# Entrega: Pescado asado

Pon aquí el GLB exportado de Tripo: **`meal_roastFish-v1.glb`**.
Si ya tiene otro nombre, déjalo tal cual; no hace falta repetir la exportación.

[Referencia PNG](../../../cooking-icons-v1/singles/meal_roastFish.png)

Resultado que se prepara y consume al momento. Mesh opcional para su representación visual.

Conserva el original. Para otra versión usa `meal_roastFish-v2.glb`; si hay texturas externas o un ZIP de Tripo, déjalos junto al modelo. El GLB preferido lleva sus texturas incluidas.

Objetivo inicial 500–800 triángulos; la jarra de grog puede llegar a aproximadamente 1.000.
Texturas derivadas 512/256 px se preparan durante la integración. No necesitas modificar `assets/manifest.json` ni copiar el original al runtime.
