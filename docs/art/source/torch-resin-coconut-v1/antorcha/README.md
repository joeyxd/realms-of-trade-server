# Entrega: Antorcha apagada

Pon aquí el GLB exportado de Tripo: **`antorcha-v1.glb`**.
Si ya tiene otro nombre, déjalo tal cual; no hace falta repetir la exportación.

[Referencia PNG](../../../torch-resin-coconut-v1/torch-tripo-reference.png)

En generación por el autor; pendiente recibir y revisar GLB.

Conserva el original. Para otra versión usa `antorcha-v2.glb`; si hay texturas externas o un ZIP de Tripo, déjalos junto al modelo. El GLB preferido lleva sus texturas incluidas.

Antorcha apagada, sin geometría de fuego: la llama se añade en el juego. Aproximadamente 1.000 triángulos.
Texturas derivadas 512/256 px se preparan durante la integración. No necesitas modificar `assets/manifest.json` ni copiar el original al runtime.
