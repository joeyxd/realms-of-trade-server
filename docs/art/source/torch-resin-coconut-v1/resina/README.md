# Entrega: Resina

Pon aquí el GLB exportado de Tripo: **`resina-v1.glb`**.
Si ya tiene otro nombre, déjalo tal cual; no hace falta repetir la exportación.

[Referencia PNG](../../../torch-resin-coconut-v1/resin-tripo-reference.png)

En generación por el autor; pendiente recibir y revisar GLB.

Conserva el original. Para otra versión usa `resina-v2.glb`; si hay texturas externas o un ZIP de Tripo, déjalos junto al modelo. El GLB preferido lleva sus texturas incluidas.

Objetivo inicial 500–800 triángulos; la jarra de grog puede llegar a aproximadamente 1.000.
Texturas derivadas 512/256 px se preparan durante la integración. No necesitas modificar `assets/manifest.json` ni copiar el original al runtime.
