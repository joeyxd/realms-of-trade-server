# GM04b — plantillas privadas de decoración

Fecha: 2026-10-10, hora de México. **Publicado y aceptado en alpha.41/protocolo 47; release `6c42e849a05a140296751daf88110c536eb4b07e` sana.** Continúa [GM04a](../gm04a/DELIVERY.md) y el [contrato previo a código](../../briefs/gm04b-templates.md).

En **Plantillas**, guarda de 1 a 120 decoraciones visibles con un nombre. Busca, renombra, elimina con confirmación y exporta/importa la biblioteca. Elegir una plantilla carga todos sus modelos y muestra el fantasma completo; cada clic añade una copia con IDs independientes y un único deshacer/rehacer. Escape termina la colocación continua. Renombrar o borrar una plantilla conserva las copias colocadas. Después puedes girarlas/escalarlas con la multiedición existente.

El origen usa el centro XZ y la menor altura de las piezas; conserva offsets, giros YXZ, escalas y círculos. No adapta cada pieza por separado a una pendiente. Los límites/capacidad se comprueban para todo el lote; un modelo ausente bloquea el conjunto. La preparación Online conserva las comprobaciones de zonas protegidas, recursos y rutas; el fantasma no anticipa todos esos rechazos ni muestra todas las huellas de colisión.

La biblioteca es privada de este navegador, cuenta, servidor y mundo; IndexedDB separado con CAS. Admite 32 plantillas y archivos de 2 MiB. Importar añade plantillas con IDs nuevos. Son compatibles con la misma semilla/revisión base: las referencias `base:*` conservan su aspecto exacto y no son portables entre semillas. Una biblioteca incompatible queda solo para exportar/reintentar. Un fallo no bloquea el borrador del mapa. Un fallo/conflicto de guardado conserva el intento en memoria para exportar o reintentar; recargar exige descartarlo explícitamente. Esa copia pendiente no sobrevive al cierre del navegador. Una apertura fallida permite reintentar y las conexiones tardías bloqueadas se cierran.

Documento v2 y protocolo 47 conservados. Las copias se expanden como instancias ordinarias; biblioteca privada y publicación del mapa son operaciones distintas. Guardado remoto, preparación/hash, activación/rollback y autoridad M5 conservan sus contratos. No hay SQL ni cambios de perfil.
