## Findings for D06a

The only immediately reusable Unreal-derived model is the already accepted crate. The repo has no other local model exports and no exported NPC merchant. Use the existing procedural merchant/stall and character looks for the first cargo/market slice; the current renderer has a `stall` prop hook, but no merchant mesh candidate was identified. There is no Dreamrise grill, fishing net, crop plot, purifier, or raft/boat mesh candidate in the bounded inventories. `SM_FishingBall.uasset` exists (26,212 B), but its name does not establish that it is a net or a working fishing asset; it has no recorded export or visual inspection.

For D06a, keep the crate appearance and spend no new art-export effort. If D06b needs a production workbench, make `SM_RepairBench` the next narrowly scoped export canary before wiring production behavior. The ActionRPG systems remain reference material for designing transfers, markets and vendor data; all economic authority, capacity, identity, and persistence must remain game-owned.
