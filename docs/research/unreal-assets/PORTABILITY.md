# Portabilidad de assets de Unreal a Marea Negra

## Alcance y evidencia

Esta matriz compara capacidades del repositorio con los tipos de contenido habituales en proyectos Unreal. Es la evaluación del runtime, previa al inventario de `C:\Unreal`; los informes por proyecto documentan la inspección posterior. No se probaron exportaciones; los resultados concretos dependen del asset, sus dependencias y la versión/configuración del exportador. Las referencias Epic describen formatos/exportador de Unreal, no garantizan que cada asset exporte sin ajustes.

Evidencia local: `docs/ASSETS.md`, `tools/import-asset.mjs`, `src/render/assets/registry.js`, `src/render/assets/manifest.js`, `src/render/assets/rebind.js`, `src/render/assets/toonmat.js`, `src/render/characters.js`, `src/render/props.js`, `src/audio/engine.js`, `src/audio/sfx.js`, `src/audio/music.js`, `src/audio/ambience.js`, `src/render/vfx/effects.js`, `src/render/vfx/particles.js`.

## Matriz

| Categoría Unreal | Portabilidad | Soporte que existe hoy y trabajo requerido |
|---|---|---|
| Static Mesh: barcos, edificios, props | **Directo tras exportar a glTF/GLB**; FBX necesita conversión a GLB. | `assets.model(id)` carga modelos genéricos; `createProps` ya conecta props enumerados y `ship:dock`. Ajusta caja y adapta materiales PBR al toon. No importa colisión, reglas de construcción ni lógica del Actor. Referencia Epic: [exportación glTF](https://dev.epicgames.com/documentation/en-us/unreal-engine/how-the-gltf-exporter-handles-unreal-engine-content) documenta Static Meshes y exportación indirecta de texturas/materiales; la [API de exportación](https://dev.epicgames.com/documentation/en-us/unreal-engine/BlueprintAPI/Miscellaneous/ExporttoGLTF) admite `UStaticMesh` y `.glb`. |
| Skeletal Mesh / personajes | **Geometría utilizable tras exportar a glTF y adaptar el rig**. | `CharacterView` y `bakeCharacter` requieren un humanoide cuyo esqueleto se mapea a los 15 huesos procedurales; huesos requeridos ausentes hacen fallar la carga. Sin skinning, el modelo queda rígido en un hueso. Epic lista Skeletal Meshes como exportables a glTF en [manejo de contenido glTF](https://dev.epicgames.com/documentation/en-us/unreal-engine/how-the-gltf-exporter-handles-unreal-engine-content). |
| Animation Sequences / clips | **Exportables, pero no reproducibles con el runtime actual.** | El importador reporta explícitamente `animations (not used: the rig animates it)`; personajes usan animación procedural del juego sobre su rig. Usar clips requeriría implementar importación, retargeting y reproducción. Epic lista Animation Sequences como exportables en [manejo de contenido glTF](https://dev.epicgames.com/documentation/en-us/unreal-engine/how-the-gltf-exporter-handles-unreal-engine-content). |
| Texturas y materiales | **Texturas: directas como imagen. Materiales: conversión/bake y ajuste visual.** | `assets.texture(id)` carga mapas de imagen; los materiales glTF de modelos se convierten en toon. No se conserva la lógica arbitraria del material de Unreal. Epic indica que glTF usa entradas PBR simples y que el exportador intenta reconocer expresiones limitadas o recurre al bake: [manejo de contenido glTF](https://dev.epicgames.com/documentation/en-us/unreal-engine/how-the-gltf-exporter-handles-unreal-engine-content). |
| Niagara / Cascade | **Recrear en el sistema de efectos del juego; assets útiles como referencia visual/de diseño.** | No hay cargador de sistemas Unreal. VFX actuales son pools de partículas, shaders y geometría Three.js en `src/render/vfx/**`; módulos, eventos, materiales y disparadores necesitarían reimplementación. La API glTF citada no enumera Niagara ni Cascade entre los tipos exportables. |
| WAV / Sound Wave | **Audio exportado a WAV puede servir como fuente, pero requiere integración de reproducción.** | `src/audio/**` sintetiza SFX, música y ambiente por Web Audio; no hay cargador de audio externo. Haría falta carga, control de buses, streaming/formatos y vinculación a eventos. Epic documenta que Sound Wave puede exportarse como WAV y que Unreal convierte internamente audio importado a WAV de 16 bits: [importación de audio](https://dev.epicgames.com/documentation/unreal-engine/importing-audio-files?lang=en-US). |
| SoundCue / MetaSound | **Recrear o traducir; diseño útil como referencia.** | No se ejecutan grafos/cues Unreal. Exportar un WAV de una señal no conserva lógica de mezcla, aleatoriedad, parámetros, atenuación o eventos; habría que trasladarlos al Web Audio/runtime nuevo. La referencia Epic de audio describe Sound Waves y formatos, no compatibilidad de ejecución de Cue/MetaSound. |
| C++ / Blueprints de gameplay o construcción | **Reimplementar en la simulación del juego; código y grafos sirven como referencia.** | No existe runtime Unreal ni importación de Blueprints/C++. Las reglas de construcción, propiedad, colisión, economía y gameplay deben convertirse a sistemas autoritativos del servidor. Los modelos pueden entrar visualmente por `assets.model`, con integración de gameplay aparte. Epic describe Blueprints como grafos de lógica en su [guía técnica](https://dev.epicgames.com/documentation/en-us/unreal-engine/technical-guide-for-blueprints-visual-scripting-in-unreal-engine); [Blueprint Header View](https://dev.epicgames.com/documentation/unreal-engine/an-overview-of-the-blueprint-header-view-in-unreal-engine?lang=en-US) genera declaraciones de variables/funciones/componentes, no porta ejecución de grafos. |

## Datos a recopilar de la carpeta fuente

- Ruta del proyecto, versión (`.uproject`), plugins del proyecto y lista de carpetas `Content/` añadidas o adquiridas con sus dependencias referenciadas; excluir módulos base de Unreal.
- Para mallas: tipo, nombre/ruta, dependencias, dimensiones, materiales, LODs; exportación GLB y FBX de origen si existe. Para personajes: jerarquía/nombres de huesos, pose de reposo y nombres de clips.
- Para materiales: material padre/instancias, texturas enlazadas y mapas disponibles; registrar si usan nodos o funciones que requieran bake.
- Para audio: WAV exportado, Sound Cue/MetaSound y referencias a sonidos, mezclas, parámetros y eventos.
- Para VFX y gameplay: Niagara/Cascade, materiales/texturas/audio referenciados, Blueprints/C++ asociados y evidencia visual del resultado o comportamiento esperado.
