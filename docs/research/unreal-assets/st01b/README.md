## SubUV and texture evidence

MyProject's hard-dependency report covers all 756 verified systems. A candidate join identified 194 systems with either a direct SubUVAnimation module reference or name-matched material/texture edges, 147 texture packages, and 578 system/material/texture edge rows. Of those, 105 systems directly reference the SubUVAnimation module; their reachable closures include 72 MaterialInstanceConstants and 101 Texture2D packages.

A bounded UE 5.8 NullRHI query loaded all 105 roots as NiagaraSystem and found 449 SpriteRendererProperties. It read exact SubImageSize values (X columns, Y rows) and renderer materials/texture parameter values: 184 renderers had a grid above 1x1; exact UObject ownership assigns them to 102 roots. A prior root-prefix attribution misassigned 101 renderers; matching the raw renderer path against `systemPackage.assetBasename:` corrected those rows with zero ambiguous or unmatched owners. There are 25 unique Texture2D packages attached to these grid renderers. A safe automatic exporter selected PNG or EXR for 24; one had no supported PNG/EXR exporter and was left untouched. This establishes serialized renderer configuration and source export support, not Niagara execution, appearance, or playability.

Normal-map texture parameters and EXR outputs are retained as source evidence, not counted as visible FX source imagery.
