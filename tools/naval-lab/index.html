Controles y lectura

Mantén W para avanzar, A/D para girar y S para frenar. Pulsa Espacio para cazar una ráfaga. El crucero asistido mantiene un avance básico; desactívalo para dejar que el barco pierda velocidad al soltar. No hay marcha atrás instantánea.

En mando: stick izquierdo para timón, RT para avanzar, LT para frenar y A para la ráfaga. En móvil, los controles aceptan varios dedos.

La línea dorada registra tu trayectoria; las figuras amarillas marcan el lastre. El aro muestra el centro de masa.

Esta bahía es independiente de tu partida. El pilotaje online, la cubierta móvil, los niveles de navegación y el viento cambiante vienen después.
